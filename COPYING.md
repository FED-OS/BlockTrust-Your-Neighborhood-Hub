# Copying

BlockTrust is free and open source software released under the **MIT License**.
The full legal text is in the [`LICENSE`](./LICENSE) file in the repository root.
This document is a plain-language summary of what that means in practice; it is
not legal advice and, in any conflict, the actual `LICENSE` text governs.

---

## What the MIT License lets you do

You are free to use, copy, modify, merge, publish, distribute, sublicense, and
sell copies of BlockTrust. You can run it personally, deploy it for your
neighbourhood, embed it in a commercial product, or build a fork with a
different focus. There is no charge, no royalty, and no requirement to
contribute your changes back — though contributions are very welcome.

The only conditions are that you must include the copyright notice and the
permission notice (the two short paragraphs in the `LICENSE` file) in all
copies or substantial portions of the software.

---

## What the MIT License does not grant

The software is provided "as is", without warranty of any kind, express or
implied. The authors and copyright holders are not liable for any claim,
damages, or other liability arising from the use of the software. In plain
terms: BlockTrust is free, but if it breaks, you own both pieces, and you cannot
sue the maintainers for it.

The licence covers the software itself. It does not cover the *content* that
users post when running an instance of BlockTrust — that content is owned by the
people who posted it, and any instance operator must set their own terms for
user-generated content in line with the project's free-speech and privacy
commitments described in `GOVERNANCE.md`.

---

## How to comply when you copy or fork

1. Keep the `LICENSE` file intact in your copy or fork.
2. Preserve the copyright line. If you make substantial changes, you may add
   your own copyright line beneath the existing one; do not remove the original.
3. If you distribute a modified version, include both the original permission
   notice and a note that the software was modified.
4. There is no requirement to rename the project, but if you keep the name
   BlockTrust for a materially different fork, please be clear in your README
   that your fork is not the canonical project.

## Third-party assets and inspirations

BlockTrust's source code is original. Any third-party assets, libraries, or
design inspirations the project relies on — currently none beyond standard web
platforms — are listed in [`CITATIONS.md`](./CITATIONS.md). If you add a
dependency, add a citation there and confirm its licence is compatible with MIT.
