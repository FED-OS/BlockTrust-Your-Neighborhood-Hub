# Social Preview & Prompts

This document records the social preview image for the BlockTrust repository and
the image-generation prompts used to create it, so the look can be reproduced or
iterated in the future. The preview image is what appears in link unfurls on
social media, in GitHub's repository social preview slot, and in chat apps when
someone shares a link to the project. A good preview signals professionalism and
gives a sense of the product at a glance.

The image file is stored at `assets/social-preview.png` (generated by the image
tool and checked into the repository). GitHub's repository social preview slot
recommends a 1280×640 pixel image, which the generation targets.

---

## The preview concept

The preview communicates three things instantly: that BlockTrust is a
neighbourhood social app, that it is a clean modern web product, and that it has
a distinctive green brand identity and a free-speech, community-first spirit.
The composition is a wide banner with the BlockTrust wordmark and tagline on the
left, a stylised phone mockup showing the app's home feed on the right, and a
soft neighbourhood-skyline silhouette behind. The palette is the project's own:
a vibrant green gradient accent on a clean dark-to-light surface.

---

## Generation prompts

### Prompt 1 — primary social preview (used)

> A wide social media preview banner for a neighbourhood social web app called
> "BlockTrust". Left side: the wordmark "BlockTrust" in a bold, friendly
> sans-serif, with the tagline "Your block, your voice." below it in a lighter
> weight. Right side: a stylised smartphone mockup showing a clean mobile app
> home feed with post cards, a green accent header, and a bottom navigation bar.
> Background: a soft, low-contrast silhouette of a residential neighbourhood
> skyline at dusk in muted teal and slate. Accent colour: a vibrant green
> gradient (#16a34a to #22c55e). Overall mood: trustworthy, modern, community-
> warm, free-speech-friendly. Flat vector illustration style with subtle depth,
> crisp edges, no photographic noise. No stock-photo people. No text other than
> the wordmark and tagline. 1280×640.

### Prompt 2 — alternative (light theme, for light-mode contexts)

> A wide social media preview banner for "BlockTrust", a neighbourhood social
> web app. Clean white background. Left: the wordmark "BlockTrust" in bold
> green sans-serif with tagline "Your block, your voice." Right: a flat vector
> smartphone showing the app's home feed in light mode with white post cards,
> green accents, and a green bottom nav. A subtle green-to-white gradient glow.
> Friendly, modern, trustworthy, community-warm. No photographic elements, no
> people, no extra text. 1280×640.

### Prompt 3 — square app-store-style tile

> A square app icon style preview for "BlockTrust". Centered green gradient
> rounded-square tile with a white minimalist neighbourhood-block glyph (a few
> simple house rooftops) and the wordmark "BlockTrust" beneath in white
> sans-serif. Flat vector, clean, modern, friendly. No extra text. 1024×1024.

## How to regenerate

1. Use the image generation tool with the prompt above.
2. Save the output to `assets/social-preview.png`.
3. If the look has drifted, iterate on the prompt and regenerate; keep the
   composition intent (wordmark + tagline + phone mockup + neighbourhood
   silhouette + green accent) stable so the brand stays recognisable.
4. Update this document if the prompt materially changes.

---

## How to set it on GitHub

1. Go to the repository → **Settings** → **Social preview**.
2. Upload `assets/social-preview.png`.
3. Save. Link unfurls on Twitter/X, LinkedIn, Slack, Discord, and GitHub itself
   will now show the preview.

The image is committed to the repository so forks and mirrors inherit it.
